# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, technically rigorous, and constructive. Harassment, discrimination,
personal attacks, doxxing, and disclosure of another person's sensitive data are
not tolerated.

Report conduct concerns privately to **security@blueteamforge.com**. Reports will
be reviewed confidentially and handled proportionately. Security vulnerabilities
must instead follow [SECURITY.md](SECURITY.md).
